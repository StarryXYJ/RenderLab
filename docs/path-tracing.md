# 路径追踪实验

运行方法见 [手册](../manual/build.md)，实际状态见
[阶段计划](../design/phaseplan.md#m8-专题深化与作品交付)。

## 图与所有权

`PipelineType::PathTracing` 注册独立的 `PathTracingFeature`：场景准备复用现有静态 Mesh
BLAS、场景 TLAS 和索引材质表；`PathTracing.Trace` 输出每帧一批 HDR 总量、主射线
直接贡献和间接漫反射贡献。三者各自写入跨帧 HDR 历史，间接镜面均值由总均值减去
直接和漫反射均值得到。历史共享样本数、失效条件、双缓冲索引和完成点；滤波开关不
重置它们，直接与漫反射历史均计入视图预算。显示 Pass 再做曝光和 Tone Mapping。
逐路径循环在 RayGeneration 中，不按每次反弹生成 Graph Pass。

历史是按视图保存的双缓冲，读写声明和完成点保护在途版本；新版本只在提交成功后发布。
路径追踪历史使用独立键，避免与混合反射数据互相复用。相机、尺寸、光照、环境、场景变换、
材质表及影响遍历的实例 mask 进入历史签名；曝光只影响显示。场景与材质变动等验证范围见
阶段计划。场景资源准备、部分参数结构与反射仍共用，当前不是独立的应用服务模块。

## 运动预览

启用 Spatial denoise 和 Reprojection 时，显示分支分别保存空间滤波后的间接漫反射与
镜面历史；二者按主射线命中位置重投影并检查世界位置、法线和材质。邻域约束与历史
长度分别计算，直接分量使用当前空间结果；新露出区域等匹配失败时不使用历史。
对低粗糙度表面，若当前及上一帧有有限的镜面采样次级距离，以虚拟点与接收点在上一帧
的投影差保守降低镜面历史置信度。镜面仍按接收表面重投影，不是完整虚拟运动矢量。
最终权重随屏幕位移降低，静止累积从 8 spp 增至 32 spp 时逐渐交回空间滤波结果。相机运动权重的有限 HDR 对照和亮区退化见 [降噪候选评估](performance/m8-denoiser-evaluation.md#相机运动基线与历史权重2026-年-11-月-12-日)。
这是有偏的交互预览，时域历史与当前空间结果可能共享样本，不能解释为独立样本或增加的 spp；
它不写入原始 HDR 累积。关闭 Spatial denoise 查看未滤波累积，或关闭 Reprojection
只保留空间滤波。场景、光照、材质、分辨率和较大相机跳变会使显示历史失效。
物体变换属于场景变化：即便只有一个物体移动，当前也会丢弃整幅图像的渐进与显示
历史；静止后重新累积。该策略避免复用旧几何，但持续运动时不能依靠跨帧历史降噪。

场景实例的 `previousWorld` 是同一 `Extractor` 上一次**成功提取**时的矩阵，首次出现、
删除后重新出现或重新启用的实例回退为当前矩阵；它不是按视图保存的上一成功提交帧。
当前 `SceneRenderer` 在图构建和提交之前提取场景，因此提取成功后若后续渲染失败，
或同一提取器被多个视图交替使用，不能假设此矩阵对应某个视图的时域历史。刚体位置
映射可用 `previousWorld * inverse(world) * currentWorldPosition`，但只有在实例
身份、几何和两次变换对应历史帧时才有意义；还需处理法线、遮挡和照明变化。
路径时域预览另外维护当前时域槽的实例变换，在 Graph 成功提交后随该槽一起发布；
它按实例 ID、模型和网格匹配，只保留一个活动视图，关闭时域或切换视图后冷启动。
`pathIdentityDiagnostics` 开启且路径时域运行时，`pathPreviousWorld` 依同帧
`allInstances` 顺序提供上一提交槽中的匹配矩阵；不存在匹配则为空。该诊断不代表
时域信号已通过相机、材质、光照或逐像素遮挡检查，同名网格的原地几何更改也不能靠
名称匹配识别。变换表在启用路径时域时按实例数占用 CPU 内存并逐帧重建，尚未测量性能。
当前并未把此矩阵接入路径重投影，也没有逐像素运动矢量。

启用时域预览需要双缓冲的五张 RGBA32F 历史图、一张临时显示图和两张滤波分量图，
逻辑总量约 208 字节/像素（实际峰值受分配与复用影响）；
直接分量与间接漫反射分量各需两张跨帧图和一张每帧图，合计约 96 字节/像素；
次级距离引导另需一张每帧 RGBA32F 图，约 16 字节/像素。均不含其它路径追踪资源；
高分辨率需注意带宽与显存。

目前没有逐物体运动矢量、准确的镜面虚拟重投影或多尺度 SVGF。
特别是曲面反射、移动物体和遮挡边缘仍可能闪烁或出现拖影，高光也可能被邻域约束压低。
当前球体场景上的实测和边界见 [降噪验证](performance/m8-path-denoise.md)。

## 可选逐样本 HDR 压缩实验

编辑器 Render Settings → Ray tracing 的 **Path HDR filter** 默认关闭；仅在 Path Tracing 且 Spatial denoise 开启时生效。关闭时使用原路径采样和滤波 Shader。命令行使用 `--path-hdr-normalize on` / `off`，`--denoise off` 时不生效。

实验采样变体在每条完整路径求和之前，以 `1 / (1 + Y(C))` 缩放总贡献 C 以及同一路径的直接和间接漫反射分量，然后逐样本累积。空间滤波开始时以累积总量的亮度计算共同的还原比例，再恢复各分量；后续应用原有压缩域空间滤波。压缩域累积不是线性 HDR 原始累积，因此切换实验或其实际生效状态会重置累积和时域历史；实验期间分量诊断读回的是压缩域值。关闭后重新按原链路采样。

这种非线性估计有偏，可能压低真实高光或改变颜色，并不解决积分器的无偏收敛。接近压缩上界时还原由 `1e-6` 保护限制。固定 Gallery 场景的白点得到抑制，但高样本全图误差明显增大；有限验证和数据见 [逐样本实验](performance/m8-path-tracing.md#逐样本-hdr-压缩实验2026-年-11-月-12-日)，不能认为白点或收敛已解决。

## 积分与材质

每像素每帧最多追踪 8 条独立抖动的主射线，每条最多追踪四段路径；样本计数表示真实路径数，末批按上限裁剪。命中 Lit 表面累加自发光及有可选阴影的
方向光，再用 50% 余弦半球、50% visible-GGX 混合分布采样方向；按完整混合 PDF 除以项目
metallic-roughness BRDF 乘余弦更新 throughput。未命中读取环境图，Unlit 命中返回基础色并结束。
采样按像素、样本、维度和 `SceneRenderOptions.pathSeed` 确定，种子默认为 0 并保持原始
序列；改变种子会重置原始与时域历史，相机重建使用同一采样种子。该选项目前用于 C++
验证，编辑器没有种子控件。原始累积不做降噪或亮度截断。主射线命中的自发光、
Unlit、可见方向光及主射线未命中的环境属于直接分量；其余反弹贡献为间接分量。
在第一次散射方向上，按完整混合 PDF 评估漫反射和镜面 BRDF 项；每个颜色通道用
漫反射项占两项之和的比例分配同一条路径的后续贡献。分量不按随机采样 lobe 归类；
RGB 光传输在当前模型中是逐通道的，未涉及光谱串色。间接镜面历史是总均值减去直接
与间接漫反射，显示侧分别以相同基础强度对漫反射、镜面邻域限幅与滤波后加回直接量。
空间滤波强度的统计方差目前仍使用合并信号。差值的微小负值为显示滤波目的截为零，可能
受浮点消减影响；原始总均值不受影响。可选 `pathComponentDiagnostics` 读回三份 HDR
历史与引导用于内部验证，默认关闭。启用诊断且开启降噪时，还读回空间滤波总量和
漫反射、镜面分量；两分量与原直接量可在浮点误差内重组空间总量。滤波被跳过的像素
保留原总量，此时镜面差值可能有极小负值；不要将其无条件截断后假设能精确重组。
诊断分量不是 NRD 输入。分量滤波管线按需创建，时域或诊断开启时产生两张分量纹理；
仅诊断开启时读回。分量时域历史也可选读回，用于验证历史长度与置信度。
`pathHdrDiagnostics` 可单独请求色调映射之前的线性 RGBA32F 显示分支读回；它不改变
历史，默认不分配读回缓冲。此读回包含所选空间和时域显示滤波，不是未滤波真值；
关闭滤波时可用于参考图。读取前须等待提交完成，并按 `TextureRowPitch` 处理行间距。

`pathIdentityDiagnostics` 是默认关闭的 C++ 验证选项，仅路径追踪可用。开启时按需创建
Ray Query 管线与独立 Graph Pass，读回首条抖动主射线身份和已有表面引导；它不参与
积分或历史更新。`SceneReadback.pathPrimaryIdentity` 为 RGBA32F：X 为类型（0 环境
未命中、1 网格、2 解析面光源），Y 为同帧快照中的实例或灯索引，Z 保留为 0，W 为
射线距离（未命中为 10000）。网格索引对应 `LastSnapshot().allInstances`，灯索引
对应 `LastSnapshot().areaLights`；索引只属于当前快照，增删对象或改变拓扑后不能
直接跨帧比较。`pathPrimarySurface` 同时读回原路径的表面引导，用于核对网格命中
距离。`pathPreviousPosition` 为 RGBA32F，XYZ 是首条主射线网格命中点经当前到
上一提交槽的实例变换后的世界位置，W 为 1 表示找到同视图的匹配变换、0 表示无
匹配或命中解析灯/环境；W 不保证上一帧该点可见或辐射历史可用。仅对未变形网格和
实例身份、几何与历史对应时可解释为上一帧位置，当前不参与重投影。读回前等待
完成点，按 RGBA32F 的 `TextureRowPitch` 访问；开启时新增两张各 16 字节/像素的
GPU 图、三份带行间距的读回缓冲和每实例 64 字节的上传数据，并增加射线查询与复制
开销。身份和位置只描述每批次第一条样本射线，不代表其余样本、阴影、间接可见性
或运动矢量。

次级距离引导记录主表面后的第一条射线长度，不包含主射线距离，也不除以 PDF 或
BRDF。批次中只合并与首个主表面的法线、距离、基础色及粗糙度近似匹配的样本，
分别对余弦和 GGX **采样分布**的正距离求调和均值；0 表示无有效样本，10000 为
环境未命中的射线最大距离，两个计数记录参与的路径数。引导按采样分布标记，不代表
对应路径的辐射只属于该 BRDF 分量；它不是已适配 NRD 的 hit-distance 输入。
当前还没有逐物体运动矢量或每分量时域滤波。
默认引导空间降噪按亮度方差估计与样本数逐渐降低强度；中位数限制与空间平均会产生偏差。可用编辑器的
Spatial denoise 或命令行 `--denoise off` 关闭。引导、性能、对照及细节损失见
[降噪验证](performance/m8-path-denoise.md)。四段上限截断更长的间接路径，
不使用俄罗斯轮盘；最多两盏显式矩形面光源通过 NEE 和 BSDF 的 MIS 采样，环境及任意发光 Mesh 暂无重要性采样。细节与限制见 [面光源](area-lights.md)。

仅支持既有内置不透明 Lit/Unlit 三角网格；Transparent 和 Masked 不支持。材质/纹理沿用有限
图集和单 mip；固定世界空间射线偏移及着色法线可能在小尺度、大坐标、薄片和强法线贴图下
出错。自发光三角形只在路径命中时贡献，低概率命中的小光源可能产生很大方差。既有 AO
贴图不作为物理遮挡参与路径积分。镜面粗糙度下限沿用现有材质契约，不是理想 delta 镜面。

BSDF/PDF 采样与独立半球数值积分、固定场景收敛结果和限制见
[验证记录](performance/m8-path-tracing.md)。有限组合的数值对照和单场景高样本对比不能证明
所有几何、材质和照明均正确。
