# 路径追踪实验

运行方法见 [手册](../manual/build.md)，实际状态见
[阶段计划](../design/phaseplan.md#m8-专题深化与作品交付)。

## 图与所有权

`PipelineType::PathTracing` 注册独立的 `PathTracingFeature`：场景准备复用现有静态 Mesh
BLAS、场景 TLAS 和索引材质表；`PathTracing.Trace` 输出一帧 HDR 样本，
`PathTracing.Accumulate` 写入跨帧 HDR 历史，显示 Pass 再做曝光和 Tone Mapping。
逐路径循环在 RayGeneration 中，不按每次反弹生成 Graph Pass。

历史是按视图保存的双缓冲，读写声明和完成点保护在途版本；新版本只在提交成功后发布。
路径追踪历史使用独立键，避免与混合反射数据互相复用。相机、尺寸、光照、环境、场景变换、
材质表及影响遍历的实例 mask 进入历史签名；曝光只影响显示。场景与材质变动等验证范围见
阶段计划。场景资源准备、部分参数结构与反射仍共用，当前不是独立的应用服务模块。

## 积分与材质

每像素每帧一条带抖动的主射线，最多追踪四段路径。命中 Lit 表面累加自发光及有可选阴影的
方向光，再用 50% 余弦半球、50% visible-GGX 混合分布采样方向；按完整混合 PDF 除以项目
metallic-roughness BRDF 乘余弦更新 throughput。未命中读取环境图，Unlit 命中返回基础色并结束。
采样按像素、样本及维度确定，累积不做降噪或亮度截断。四段上限截断更长的间接路径，
不使用俄罗斯轮盘，也不做面光源或环境重要性采样。

仅支持既有内置不透明 Lit/Unlit 三角网格；Transparent 和 Masked 不支持。材质/纹理沿用有限
图集和单 mip；固定世界空间射线偏移及着色法线可能在小尺度、大坐标、薄片和强法线贴图下
出错。自发光三角形只在路径命中时贡献，低概率命中的小光源可能产生很大方差。既有 AO
贴图不作为物理遮挡参与路径积分。镜面粗糙度下限沿用现有材质契约，不是理想 delta 镜面。

BSDF/PDF 采样与独立半球数值积分、固定场景收敛结果和限制见
[验证记录](performance/m8-path-tracing.md)。有限组合的数值对照和单场景高样本对比不能证明
所有几何、材质和照明均正确。
