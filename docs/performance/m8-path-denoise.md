# 路径追踪显示降噪验证

## 方法与边界

`PathTracing.Denoise` 读取未滤波的 progressive HDR 总均值、主射线直接贡献均值，
以及当帧主射线的法线、距离、基础色与粗糙度引导。它对总量减直接量的间接分量滤波，
再加回直接量；统计方差仍按总量计算。它在相近表面/材质的 3×3 邻域内用亮度中位数限制异常值并做空间
加权，结果仅用于显示，绝不写回累积历史。每像素另外维护亮度的均值和 M2，
以标准误差估计噪声；滤波强度同时乘以 `min(1, 512 / spp)`，随样本增长渐弱。
背景和 Unlit 旁路。由于使用当前帧抖动的引导，没有运动矢量或时间重投影，边缘可能
闪动；限制亮度和空间平均均有偏，可能压低真实高光、模糊反射或细节。它不是无偏估计器，
也不是通用实时去噪器。编辑器 Ray tracing → Spatial denoise 或命令行 `--denoise off`
可关闭，保留原始结果。

每帧最多生成 8 条路径并合并批次均值及亮度统计；累积使用真实样本数，末批裁剪。
每帧生成两张 RGBA32F 引导图，即使关闭滤波也会产生；另有批次及跨帧统计 Buffer，
启用滤波时再生成一张 RGBA32F 显示图。
这是额外的显存与带宽成本，尤其在高分辨率；未验证 4K、其他 GPU 或长期交互。

或其他设备保证。原始日志为 `out/m8-temporal-performance-{on,off}.log`。

## 运动序列复核与历史权重修订

2026 年 11 月 10 日，RTX 5060、Release、DX12、validation 开启，Gallery 128×72；
每条轨迹预热 8 帧、移动 8 帧、停下 4 帧。慢速为每帧平移 0.02、旋转 0.15 度，
快速为 0.08、0.8 度，`reveal` 为 0.12、-0.6 度；后者是横移方向变化的压力轨迹，
尚未用几何真值标记实际新露出区域。对每个运动位置单独生成 4096 spp 未滤波参考，
静止帧沿用终点参考；相同随机序列比较空间与时域显示。像素为最终 sRGB 8 位 RGB。

| 轨迹 | 全序列 MSE 空间 / 时域 | 帧间残差变化 MSE 空间 / 时域 | 球体包围裁剪 MSE 空间 / 时域 | 停止后 MSE 空间 / 时域 |
| --- | ---: | ---: | ---: | ---: |
| gentle | 60.071 / 58.350 | 59.478 / 48.602 | 201.080 / 195.268 | 48.515 / 48.664 |
| fast | 61.168 / 60.395 | 66.229 / 58.394 | 202.796 / 200.331 | 54.317 / 54.360 |
| reveal | 61.821 / 61.047 | 91.245 / 88.742 | 186.243 / 184.142 | 54.708 / 55.118 |

球体裁剪为固定屏幕坐标 x=[30,100)、y=[25,60)，包含相邻地面，非几何分割。
残差变化是在同一屏幕像素比较相邻帧的误差之差，不是光流补偿后的闪烁或主观评价。
参考依然有噪声，所有数字仅适用于本机、此分辨率与单条随机序列；时域在停止后
四帧的 MSE 仍略高，不能声称完全消除拖影。原始帧和 JSON 保存在
`out/build/m5-release/reflections/<backend>/path-sequence`；Debug 使用 256 spp
参考仅检查运行和历史状态，不做上述画质断言。

修订按当前点映射到上一帧的像素位移衰减显示历史，并在双线性有效支持不超过 0.1 时
丢弃历史，避免使用未归一化的少量值；静止交接从 128 spp 缩短到 32 spp。逐帧
序列回归为全画面、球体裁剪、停帧和残差变化设置宽松退化上限，避免将固定种子上的
细微优势当作跨场景保证。以上指标也未确认遮挡边界或镜面高光的像素级正确性。

## 主射线直接光分离

RTX 5060、Release、DX12、640×360 Gallery，固定种子，关闭时域滤波；对比原版约
19948 spp 未滤波截图的 sRGB 8 位 RGB MSE。前版滤波与本版分别为：512 spp
7.3473 / 5.2825，2048 spp 3.1039 / 2.9999，8192 spp 0.8191 / 0.8133。
对应本版未滤波 MSE 为 11.4658 / 3.9902 / 0.8665。两版 512 spp 未滤波截图
逐像素一致；参考仍有噪声且共享样本，不是无偏性证明。DX12/Vulkan GPU 合成测试
另外验证直接高光不被压制或扩散，间接孤立亮点仍被滤波。

同一个 128×72 固定慢速相机序列及 4096 spp 每位置参考，本版空间 / 时域序列
MSE 为 44.2156 / 42.8970，球体包围裁剪为 146.4747 / 141.7190；对应前版
时域为 58.3504 和 195.2676。新时域平均有符号误差约 -0.445，前版约 -0.250，
因此 MSE 改善并不代表亮度偏差消失；高光、快速运动和遮挡仍需逐区域视觉验收。
结果位于 `out/m8-separated` 与 `out/build/m5-release/reflections/<backend>/path-sequence`。
另一个 RayTracing 场景 160×90，以旧版约 4097 spp 参考，旧版 65 spp 未滤波 / 滤波
MSE 为 24.3822 / 14.8151，本版 64 spp 为 24.6674 / 9.2858；样本数并非完全一致，
数据在 `out/m8-direct-scene` 与 `out/m8-denoise/small-64-*`。

同机 Release DX12 640×360、validation 关闭，32 帧预热和 128 帧串行 headless
短测，分离前 / 后墙钟吞吐约 719.6 / 684.3 FPS，跟踪分配峰值约 69.2 / 80.4 MiB。
本版 Trace / 直接累积 / 降噪 / 时域 Pass 均值约 0.718 / 0.017 / 0.049 / 0.080 ms；
单次短测包含其他波动，不是窗口帧率或其他 GPU 保证。数据见
`out/m8-temporal-performance-on.log` 与 `out/m8-direct-perf.log`。直接分量的瞬态
样本图和两张跨帧图约增加 48 字节/像素；即使关闭滤波也继续维护直接历史，以便开关
时与总历史对齐。

## BSDF 采样比例候选（已撤回）

同日尝试根据材质改变余弦漫反射与 visible-GGX 的混合概率，采样器和混合 PDF
同步调整；在 RTX 5060 的 Release DX12/Vulkan BSDF 半球数值积分测试通过，但固定
Gallery 整体画质未改善。第一版以 Fresnel/漫反射亮度估计概率；第二版保留介质原来的
50/50，仅将纯金属的镜面概率提高到 95%，并保留原采样选择顺序。两版均已撤回，
当前积分器仍使用 50/50。

第二版以自己的约 19944 spp 截图作共同参考，640×360、滤波关闭的旧 / 候选 MSE：
512 spp 为 11.6216 / 12.4030，2048 spp 为 4.1955 / 4.6050；候选孤立亮点
分别为 202 / 81，旧版为 147 / 65。参考与候选共享样本，旧版与其也并非完全独立，
单参考和启发式亮点不证明任意场景退化，但不足以支持合入。旧 / 候选两张约 20k spp
图之间 MSE 为 0.3503；不能当作真值或无偏性证明。结果在
`out/m8-bsdf-metal-paired`、`out/m8-convergence-baseline` 与 `out/m8-batch-compare`。
后续应使用多种子、独立参考和分离的间接光/材质区域再研究方差来源。
