# 路径追踪降噪候选评估

2026 年 11 月 10 日。实际实现、测试与阶段状态以 [阶段计划](../../design/phaseplan.md)
为准；此文仅记录当前候选、依赖和实测结果，不表示 NRD 已接入或在本项目运行。

## 多种子运动基线

RTX 5060、Release、128×72 Gallery，三条轨迹均先预热 8 帧，再运动 8 帧并停下
4 帧；每帧 8 spp。对空间滤波和现有合并时域预览使用相同的候选种子 1、2、3，
分别对比每个姿态上关闭滤波、使用种子 1000 的 4096 spp 参考。下面是 DX12 的
8 位 sRGB RGB MSE 范围，每组依次为空间 / 时域，范围来自三个种子：

| 轨迹 | 全序列 | 停止后四帧 |
| --- | --- | --- |
| gentle | 43.735–48.376 / 41.840–47.601 | 30.982–37.260 / 31.458–37.395 |
| fast | 42.488–46.002 / 42.016–45.163 | 29.685–33.033 / 30.034–33.364 |
| reveal | 42.526–46.317 / 41.793–45.735 | 32.291–36.835 / 32.770–37.717 |

本轮九组全序列 MSE 的时域值均略低，停止后四帧均略高；指标不证明主观画质改善。
Vulkan 同一设备上数值接近，逐种子、球体裁剪与残差变化见各后端
`out/build/m5-release/reflections/<backend>/path-sequence/<trajectory>/seed-*/metrics.json`。
参考仍是有限样本、单个种子的有噪声参考；数字受场景、曝光和 8 位色调映射影响，
不能当作无偏 HDR 真值或完整遮挡与运动画质验收。不同种子确定不同伪随机流，并非
对统计独立性作数学证明。Debug 参考仅 256 spp，不用于上表质量结论。

## 三种子线性 HDR 参考

同一 128×72 Gallery 轨迹中，显示结果在曝光和色调映射之前以 RGBA32F 读回；每个
参考姿态关闭滤波，分别以种子 1000、1001、1002 追踪 4096 spp，并在线性空间取平均。
候选继续使用种子 1、2、3，对比空间滤波与分量时域预览。RTX 5060、Release/DX12
线性 RGB MSE，范围来自三个候选种子，依次为空间 / 时域：

| 轨迹 | 全序列 | 停止后四帧 |
| --- | --- | --- |
| gentle | 0.024130–0.030006 / 0.024117–0.027755 | 0.004574–0.014346 / 0.004498–0.014339 |
| fast | 0.015262–0.036412 / 0.015107–0.036114 | 0.011609–0.015602 / 0.011606–0.015580 |
| reveal | 0.019977–0.028677 / 0.019963–0.028611 | 0.006344–0.017092 / 0.006343–0.017091 |

九组全序列与停帧线性 MSE 的时域值均略低，但多数差距很小；此对照不证明主观画质
改善。单独参考种子、均值与候选保存为线性 RGB PFM，逐组指标见
`out/build/m5-release/reflections/<backend>/path-sequence`。独立脚本复算 gentle
seed 1 的全序列 MSE 与报告一致，且检查三个参考种子不同、均值误差不超过
1.6e-7。伪随机种子不构成统计独立性的数学证明；参考仍有有限样本误差，且测试只
覆盖固定场景和相机运动。Debug 参考每种子仅 256 spp，不用于此表。

## 移动物体历史失效

RTX 5060、Release、96×54 Gallery，固定相机并逐帧移动一个可见球体，共移动四帧，
随后静止两帧；两次独立运行分别关闭和开启时域预览，使用相同种子。DX12 与 Vulkan
均观察到首末两个移动位置的线性 HDR 图有 207 个像素的 RGB 差绝对值之和大于 0.2。
这只确认该测试中的几何运动影响了画面，并非逐像素遮挡真值。

每次物体变换都使未滤波渐进历史从 8 spp 重新开始，时域历史从第一帧开始；四个移动
帧中，开启与关闭时域的线性 HDR 逐通道最大差异为零。停止后渐进样本恢复到 16、24
spp，开启时域的历史长度恢复到 2、3 帧。测试及图片在
`D:/Personal/RenderLab/out/path-moving-object-second/<backend>/path-moving-object`。
这些结果验证当前全局失效与恢复策略，不代表已实现逐物体运动矢量、区域级历史
保留、遮挡真值或对快速物体和真实窗口画质的完整验收。

## 两点漫反射亮点限幅

三种子 HDR 对照中的 gentle/seed 3、第 8 个运动帧，在像素 (46,36) 的红色通道
原始总量为 42.527、间接漫反射为 41.275；空间结果未改变，三种子参考为 0.306。
诊断确认它只有中心和一个通过法线、深度与材质检查的邻居，原实现因少于三个样本而
旁路。新规则仅在两点匹配且中心间接漫反射亮度超过较低值的 4 倍加 0.08 时限幅，
不修改该分支的镜面；对这个像素，空间/时域显示从 42.527/28.704 降至 1.469/1.095，
仍高于参考。场景专项同时检查异常漫反射下降和该像素镜面不变。

RTX 5060、Release/DX12，三条 128×72 运动轨迹、各三个候选种子和每姿态三种子
4096 spp HDR 参考，时域预览的九组线性 HDR MSE 均下降约 0.08%–11.12%，8 位
sRGB MSE 均下降约 0.34%–2.37%；球体裁剪、停帧与帧间残差 MSE 也均下降。这里
比较旧版空间+时域与新版空间+时域，参考未滤波且不变。对变化超过 1e-5 的线性颜色
通道单独检查，三条轨迹分别有 2145、2060、1765 个通道变化，其中约三分之二与有限
参考的单通道平方误差增加；限幅会引入局部偏暗，不能声称每处都改善。Vulkan 的
专项通过，结果趋势相近。原始/滤波分量、三种子 PFM 与指标分别在
`D:/Personal/RenderLab/out/hdr-component`、`D:/Personal/RenderLab/out/hdr-diffuse-guarded`。

640×360 固定 Gallery、时域关闭，在 504 和 8184 spp 的 DX12 截图与旧版逐字节一致；
这只是该静止位置和种子。640×360、32 帧预热、128 帧单次短测旧/新 RHI 峰值均
110.4 MiB，Denoise 约 0.075/0.072 ms，不能据此判断稳定性能差异；数据在
`D:/Personal/RenderLab/out/hdr-static` 和 `D:/Personal/RenderLab/out/hdr-guarded-perf`。
未验证动态物体、镜面亮点、多设备及用户主观画质，也不保证真实漫反射高光不会被压暗。

## 分量时域修正候选（已撤回）

尝试对渐进间接漫反射与镜面分别保存历史，用现有主表面重投影和邻域限幅，镜面
历史额外乘视差置信度；再把两项相对当前间接分量的时域差值加到既有空间滤波结果。
直接光没有单独累积时域历史。该候选会增加一组双缓冲 RGBA32F 镜面历史，且没有对
两种当前分量先分别做与显示结果一致的空间重建。

RTX 5060、Release/DX12 的 128×72 固定运动端点首项检查，空间基线 8 位 sRGB RGB
MSE 为 47.324，候选为 60.998，未满足现有测试的改善条件，故撤回。差值修正使用的
分量与空间结果不一致可能引入额外误差；本次未做消融，不能将其当作已证实根因。
没有继续运行多种子或 Vulkan 候选画质测试，也未测性能。候选补丁和三张图保留在
`out/m8-component-temporal-candidate.patch` 与 `out/m8-multiseed-baseline/`。
后续应先产生与显示组合一致的独立滤波分量，再设计重投影与组合，对照同一多种子基线。

## 分量空间结果的独立时域预览

使用与显示组合一致的空间滤波漫反射/镜面结果，分别进行邻域限幅、接收表面重投影
及有限历史累积，直接项使用当前结果。镜面历史单独受粗糙度、次级距离估计的视差
置信度约束；两项的时域差值加回当前显示结果。两项使用同一主表面几何检验，未计算
准确镜面虚拟重投影，仍是有偏预览，不写入渐进 HDR 历史。

RTX 5060、Release、DX12，沿用上述三个轨迹各三个候选种子及 4096 spp 独立种子
参考：九组全序列和停帧 MSE 均低于原合并历史；全序列范围从 gentle
41.840–47.601、fast 42.016–45.163、reveal 41.793–45.735，分别变为
41.352–45.876、40.481–43.940、40.963–44.840。八组帧间残差 MSE 下降，gentle
seed 1 从 32.398 小幅升至 32.425；这不是主观画质或所有场景通过的结论。Vulkan
同一设备结果接近；逐组数据见 `D:/Personal/RenderLab/out/pc{3,6,7}/<backend>/path-sequence`。
参考仍是单个种子的有限样本 8 位图，球体裁剪还包含地板，遮挡边界、动态物体、真实
窗口交互与多种子 HDR 真值未验证。

640×360、32 帧预热及 128 帧测量、DX12 单机短测，旧/新 RHI 跟踪峰值约
95.4/110.4 MiB；PathTracing.Temporal 两次旧/新约 0.092/0.129–0.142 ms，Denoise
约 0.063–0.064/0.072 ms。旧 FPS 484–595、新 514–559，波动过大，不推断稳定帧率
差异。实验共四次交错运行，日志见 `D:/Personal/RenderLab/out/pc-perf`；其它硬件、
分辨率和真实窗口输入延迟未测。额外两张分量图及双缓冲镜面历史的逻辑成本为
64 字节/像素，实际分配受图资源复用和布局影响。

## 间接光宽尺度候选（已撤回）

在直接光分离后的空间滤波后，试验额外 stride-2、3×3 邻域尺度；按表面法线、距离、
材质、亮度及总信号方差限制权重，只平滑间接信号。RTX 5060、Release/DX12、Gallery
640×360、时域关闭，以原版约 19948 spp 参考计算 8 位 sRGB RGB MSE：

| 样本 | 已保留的直接光分离 | 额外宽尺度 |
| --- | ---: | ---: |
| 64 | 9.4065 | 9.4741 |
| 512 | 5.2825 | 5.4185 |
| 2048 | 3.0000 | 2.7385 |
| 8192 | 0.8133 | 0.7943 |

64/512 spp 的 MAE 分别从 0.8406/0.5604 降至 0.7802/0.5266，但 MSE 变高。
在 128×72 的慢速、快速、横移三条轨迹中，与已保留版本相比，时域球体裁剪 MSE
分别由 141.719/141.401/129.203 升到 142.591/142.207/129.617，停帧 MSE
也分别升高。裁剪含相邻地面；统计口径与参考限制见 [降噪对照](m8-path-denoise.md)。
因此该候选撤回，未作为通用多尺度结果；回滚后 512 spp 输出与已保留版本逐像素一致。
原始候选 `out/m8-atrous`，运动基线 `out/m8-direct-sequence-baseline`；候选序列
因后续回归可能覆盖 `out/build/m5-release/reflections/dx12/path-sequence`，以本文
数字和固定源码历史为准。候选只做了 DX12 短测，不代表其他后端结果。

## NRD 接入适配评估

只读核对 [NRD README](https://github.com/NVIDIA-RTX/NRD/blob/c862a54f4ed845378eeebd832491eebdc203c537/README.md)
及 [许可证](https://github.com/NVIDIA-RTX/NRD/blob/c862a54f4ed845378eeebd832491eebdc203c537/LICENSE.txt)，
审查时 master 为 `c862a54f4ed845378eeebd832491eebdc203c537`，README 标识 v4.18.0。
NRD 的 REBLUR/RELAX 支持漫反射与镜面信号，支持 D3D12/Vulkan，并提供 NRI 集成层
或由引擎实现 NRD API 的两种集成方式。公开 README 引用的 RTX 4080 / 1440p 成本
仅适用于其设置，不可当作本项目 RTX 5060 的实测。该版本使用 NVIDIA RTX SDK 许可，
接入或分发前需要核对其具体条款；这里没有下载、链接或分发 SDK。

当前缺口：

- 当前已基于主命中处 BRDF 两项与同一混合 PDF 输出间接漫反射，并以总量减去直接量
  和漫反射得到镜面；这不是按随机采样 lobe 归类。已通过有限半球积分与场景重组检查，
  已有多种子对照单一独立种子参考的初步运动基线，但尚未建立多种子 HDR 参考；
  该分量表示不自动满足 NRD 信号与打包契约。
- 主射线引导含世界法线、射线距离和粗糙度，但不是 NRD 所需完整输入：还需要约定
  非抖动相机/物体运动、view-space Z、准确的 normal/roughness 打包。已有按采样分布
  聚合的首个次级距离，但不是经过 NRD 分量选择、缺样重建和打包验证的 hit distance。
  当前静态物体可从矩阵重投影，不能据此宣称已有动态物体运动矢量。
- NRD 描述要求按漫反射和镜面做材质去调制，并对概率式 lobe 选择处理 hit distance
  缺样、预处理和采样概率；当前合并的总辐射统计不能直接替代这些信号。
- RHI 的 storage texture 范围目前为 RGBA8、RGBA32F 和 R32F。NRD 各内部资源、
  格式、描述符与同步需求尚未对本 RHI 做逐项运行核验；选择直接映射 NRD dispatch
  或 NRI 层前，必须设计 Render Graph 可声明的资源状态、持久历史和完成点，不能让
  外部库暗中管理状态。高分辨率显存与动态尺寸重建需实测。

建议继续定义并验证分量的次级 hit-distance、材质去调制与运动引导契约，再以可关闭的独立 Render Graph 分支做 DX12 与
Vulkan 对照，分别记录许可证/构建方式、重置和资源寿命、画质及实际成本。NRD 不应
取代未滤波 HDR 参考，也不能从它支持 Vulkan 推断已在本项目或其他硬件通过验证。
