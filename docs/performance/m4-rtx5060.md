# M4 初始性能与内存基线

采集日期：2026 年 10 月 26 日。设备为 NVIDIA GeForce RTX 5060，Windows x64，MSVC 19.51.36257、DXC 1.9.0.5512；实际驱动与配置保存在下列原始 JSON。使用标准 windows-release、关闭 validation，1280×720、Medium（512² 阴影）、最终画面、固定场景相机，预热 5 帧后测量 120 帧。各运行依次执行，未并行运行构建或 GPU 测试。

| 场景 / 后端 | CPU render 均值 ms | GPU Pass 均值合计 ms | RHI 当前 / 峰值 MiB | 进程 working set / private MiB |
| --- | ---: | ---: | ---: | ---: |
| Pbr / DX12 | 7.635 | 0.038 | 23.44 / 24.75 | 86.20 / 109.62 |
| Pbr / Vulkan | 1.946 | 0.037 | 22.88 / 22.89 | 108.22 / 141.93 |
| Shadow / DX12 | 5.701 | 0.068 | 28.38 / 29.44 | 77.07 / 116.75 |
| Shadow / Vulkan | 1.770 | 0.068 | 27.88 / 27.88 | 79.51 / 130.99 |

Pbr 场景可见 9/9 个实例，主光阴影关闭（仍保留供 Lit 绑定的 1×1 空白图）；Shadow 场景可见 4/4 个实例，包括实体、Masked、透明与地面。GPU 合计仅相加已测量 Pass 范围，不包括图间屏障、查询解析、等待或 Present，不能据此推导完整帧 FPS。此 headless 基线逐帧等待以独立读回 GPU 结果；CPU render 计时在等待前停止，包含场景/材质、Graph 和提交工作。

CPU 准备成本明显高于这些小场景的 GPU 范围。首版仍逐 Draw 创建常量和绑定组；DX12 图录制均值在 Pbr/Shadow 中分别为约 2.774/1.613ms，Vulkan 为约 0.105/0.083ms。这提供后续检查材质准备、绑定分配与提交方式的入口，不代表不同 GPU 或大型场景的结论。

RHI 当前分配在测量结束时记录，高水位包含本次进程内启动/上传；它统计引擎跟踪的原生分配，不包含驱动全部占用。进程 working set/private 在写报告时查询，headless 运行已完成最后截图；截图不计入 120 帧的时间样本。JSON 同时保留每个指标的 min/max/count，便于区分均值与波动。

最后的 1280×720 截图也做双后端比较：Pbr 最大差异为一个显示 code，Shadow 有少量 PCF 边缘差异，最大 16 个 code；逐像素计数见 [比较记录](m4-rtx5060/image-comparison.json)。小尺寸自动专项参考中的最大差异为 2 个 code，不能用它替代较高分辨率的实际比较结果。

原始记录：[Pbr DX12](m4-rtx5060/pbr-dx12.json)、[Pbr Vulkan](m4-rtx5060/pbr-vulkan.json)、[Shadow DX12](m4-rtx5060/shadow-dx12.json)、[Shadow Vulkan](m4-rtx5060/shadow-vulkan.json)。复现命令见 [构建手册](../../manual/build.md#m45-演示与-player)，计时与资源生命周期见 [工具契约](../m4-tools.md)。该记录是初始基线，无多次独立运行的统计区间，也不是性能目标或跨后端排名。
