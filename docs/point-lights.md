# 点光源（实现中）

场景对象可包含 `pointLight`：`color` 是非负线性 RGB，`intensity` 是非负光强（坎德拉），`range` 是大于零的世界空间截断距离，`enabled` 控制参与提取。位置来自层级世界变换，缩放不改变光强和范围；继承父对象启用状态，提取按对象 UUID 排序。

当前 Forward、Deferred、Indexed 和混合管线主表面使用最多八盏点光源。直接光按 `intensity / distance²` 衰减，并在 range 内乘以 `saturate(1 - (distance / range)^4)^2` 平滑截断；极近距离使用下限避免数值奇异。颜色乘光强后作为 PBR BRDF 的入射项。上限外明确报错。此有限范围窗是实时近似，范围内并非严格物理点源；没有点灯发光几何。自定义 Shader 必须自行消费对应灯数据。

普通光栅和透明物体目前没有点光源阴影；混合管线不透明主表面使用逐灯有限距离 Ray Query，遮挡结果存入独立的八位可见性掩码，反射命中表面也进行逐灯照明和遮挡查询。每像素最多八条主表面遮挡射线，未做点灯降噪或性能验收；混合反射的点灯画质尚无专门验证。Path Tracing 在每个可连接路径顶点显式连接所有点光源，以有限距离 Ray Query 检查三角形和解析矩形灯遮挡；理想点源为 delta 分布，不与 BSDF 命中进行 MIS。光源变化会失效路径和时域历史。每个顶点最多八条遮挡射线，采样、烘焙和 ReSTIR 尚未实现。现有编辑器以场景文件提供组件，没有点灯 Inspector。后续能力和验证状态见 [阶段计划](../design/phaseplan.md)。
